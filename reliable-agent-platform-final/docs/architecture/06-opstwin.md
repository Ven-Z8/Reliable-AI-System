# OpsTwin

## Purpose

Provide a synthetic enterprise environment for a secure, evidence-first, multi-agent incident commander.

## MCP servers

- scheduler;
- database;
- files/logs;
- ticketing.

## Agent components

- triage router;
- typed planner;
- scheduler investigator;
- data investigator;
- file/log investigator;
- evidence verifier;
- remediation proposer;
- incident communicator.

These are bounded components, not open-ended conversational personas.
