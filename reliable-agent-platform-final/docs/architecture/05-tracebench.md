# TraceBench

## Purpose

Explain why one agent trajectory succeeded and another failed.

## Capabilities

- trace waterfall;
- run comparison;
- state transition comparison;
- repeated-action detection;
- oscillation detection;
- retrieval-stage diagnostics;
- cost and latency analysis;
- evaluation annotations;
- first-divergence analysis.

Raw prompts, tool arguments, documents, and secrets are excluded from telemetry by default.
